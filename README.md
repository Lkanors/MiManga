# MiManga

Читалка манги на русском для Android: каталог из нескольких источников,
объединённый в один, чтение глав, списки, оценки и комментарии.

Приложение — только клиент. Всё, что оно показывает, приходит с сервера
(отдельный проект, в этот репозиторий не входит): он обходит русские сайты,
объединяет одинаковые тайтлы в одну карточку и отдаёт каталог одним API.

## Что внутри

- Kotlin, Jetpack Compose (Material 3), Hilt, Ktor, Coil, DataStore.
- minSdk 26, targetSdk 35, Kotlin 2.1, AGP 8.7, Gradle 9.3.
- Один модуль `:app`, внутри — `core` (сеть, тема, общие элементы),
  `data` (API сервера, хранилища), `domain` (модели и интерфейсы),
  `feature` (экраны: главная, каталог, тайтл, читалка, аккаунт, настройки).

Подробный разбор — в [ARCHITECTURE.md](ARCHITECTURE.md): что где лежит, почему
сделано так и какие решения чего стоили.

## Сборка

Нужны JDK 17 и Android SDK (путь к нему — в `local.properties`,
`sdk.dir=/путь/к/android-sdk`).

```bash
./gradlew :app:assembleRelease     # APK: app/build/outputs/apk/release/
./gradlew :app:testDebugUnitTest   # тесты чистой логики, без устройства
```

Ставить на телефон нужно именно `release`: отладочная сборка Compose заметно
медленнее на списках с обложками. Подписывается она отладочным ключом —
приложение ставится вручную, а не из магазина.

Готовый APK лежит в [релизах](../../releases).

## Свой сервер

Адреса сервера в репозитории нет: у сервера нет доменного имени, сертификат
самоподписанный и закреплён в приложении (оно не принимает никакой другой).
Поэтому и адрес, и сертификат — настройка сборки.

Задаются они в `local.properties` (файл локальный, в репозиторий не попадает):

```properties
sdk.dir=/путь/к/android-sdk
mimanga.serverUrl=https://192.0.2.10:8443
mimanga.serverHosts=192.0.2.10
mimanga.serverCert=/путь/к/server.crt
```

То же самое можно передать сборке (`-Pmimanga.serverUrl=...`) или положить в
переменные окружения `MIMANGA_SERVER_URL`, `MIMANGA_SERVER_HOSTS`,
`MIMANGA_SERVER_CERT`.

- `mimanga.serverUrl` — адрес API.
- `mimanga.serverHosts` — адреса, на которые распространяется закрепление
  сертификата; через запятую, если сервер доступен и из локальной сети.
- `mimanga.serverCert` — PEM-файл сертификата сервера. Из него сборка делает
  `res/raw/server_cert.pem` и правило сети `res/xml/network_security_config.xml`.

Без этих настроек проект собирается с адресом-заглушкой `https://10.0.2.2:8443`
и учебным сертификатом `app/certs/sample_server.pem`: приложение запустится, но
ни к какому серверу не подключится.

## Материалы 18+

Тайтлы с тегами «Хентай», «Эротика» и подобными сервер не показывает, пока
человек не вошёл в аккаунт и не указал дату рождения, по которой ему есть
восемнадцать. Возраст спрашивается при регистрации и задаётся один раз; у кого
он уже указан, есть переключатель «Показывать 18+» на вкладке аккаунта.

Гость такие тайтлы не видит нигде: ни в каталоге, ни в поиске, ни по прямой
ссылке на карточку.

## Лицензия

Проект учебный и личный. Манга и обложки принадлежат их правообладателям;
приложение ничего не хранит и показывает то, что отдаёт сервер.
